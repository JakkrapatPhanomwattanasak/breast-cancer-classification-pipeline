# Machine Learning Pipeline Project

## Overview
This project focuses on building a complete machine learning pipeline from raw data
to evaluated results using a structured and reusable approach.

## Project Status
🚧 In Progress

## Planned Features
- Data preprocessing and feature engineering
- Model training and evaluation
- Model comparison and experimentation
- Reusable pipeline components

## Tech Stack
- Python
- Pandas
- Scikit-learn

## Folder Structure (Planned)
src/
  preprocessing/
  features/
  models/
  evaluation/

## Notes
The goal of this project is to practice building maintainable and reusable ML pipelines
in a production-like development workflow.
